# Management DASHBOARD

## Purpose
- Single-pane overview for PMs and stakeholders to find decisions, PRD, current milestones, and action items.

## Top-level links
- [Project Charter (project-charter.md)](project-charter.md)
- [PRD (prd.md)](prd.md)
- [Recent meeting minutes (minutes-of-meetings/)](minutes-of-meetings/)
- [Latest sprint review (sprint-reviews/)](sprint-reviews/)

## At-a-glance status
- Current milestone: [fill milestone title]
- Upcoming reviews: [dates]
- Open action items: N (link to minutes)

## Actionable items
- Review PRD changes (owner)
- Confirm acceptance criteria for feature X
- Approve go/no-go for release Y

## Who updates this
- Project Manager keeps milestones and action items current.
- Editors should link back to supporting docs (designs, TRD, RFCs) when referencing technical items.

## Maintenance
- PM to reconcile open action items weekly; close items with a linked minutes file or PR.
- Archive older milestones and annotate changes in PRD version history.
